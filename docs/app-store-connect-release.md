## プロダクトページ文案

### プロモーション用テキスト

> 気圧の変化を見える化。都道府県を選ぶだけで、48時間の気圧推移と体調変化の目安をすばやく確認できます。

### 概要

> ソラケアは、気圧の変化と気象病リスクの目安を確認できるアプリです。端末の位置情報を使わず、都道府県の代表地点から表示エリアを選択できます。
>
> 初期地点は東京都です。都道府県プルダウンと、都道府県名・代表地点名の簡易検索で切り替えられます。GPS、位置情報権限、バックグラウンド追跡は使用しません。
>
> 主な機能:
> - 現在の気圧、気圧変化、体調変化の目安を表示
> - 48時間の気圧推移グラフ
> - iPhoneのホーム画面ウィジェット（Small / Medium）
> - 47都道府県の代表地点選択と簡易検索
>
> 選択地点は端末内に保存し、ユーザーアカウント、広告、行動追跡には使用しません。
>
> ※表示内容は医療上の診断・治療を目的としたものではありません。体調に不安がある場合は医療専門家へ相談してください。

## App Privacy申告案

端末の位置情報サービスは使用せず、位置情報権限も要求しません。アプリ内カタログにある公開の代表地点をユーザーが選び、その地点の気圧データを照会します。App Store Connectの最終入力は、公開版バックエンドの実際の送信内容とAppleの定義を確認して確定します。

| 項目 | 入力案 |
| --- | --- |
| データタイプ | Locationは収集しない案 |
| 利用目的 | 端末GPSではなく、ユーザーが選んだ代表地点をApp Functionalityに使用 |
| ユーザーへの関連付け | No（アカウント・識別子と関連付けない） |
| トラッキング | No |
| その他 | 広告、分析SDK、アカウント、購入情報、連絡先、写真、健康情報は取得しない |

## App Review notes 文案

> 本アプリはアカウント登録・位置情報権限なしで利用できます。都道府県プルダウンまたは簡易検索で代表地点を選択し、気圧データを表示します。アプリ内の「i」ボタンから地点設定とデータ提供元を確認できます。ホーム画面ウィジェットは、アプリを起動してデータを更新した後に追加してください。レビュー時はインターネット接続が必要です。
