# 検証スクリーンショット

以下は、Xcode 27.1のSimulatorで位置情報権限を要求せず、都道府県の代表地点を選択してAPIからデータを取得した状態を撮影した提出候補です。

- `atmo-iphone18pro-main.png`: iPhone 18 Pro、1206×2622。6.3インチ用の候補。
- `atmo-ipad-pro13-main.png`: iPad Pro 13-inch (M5)、2064×2752。13インチiPad用の候補。
- `atmo-iphone17e-main.png`: iPhone 17e、1170×2532。補助的な動作確認用。
- `solacare-widget.png`: iPhone 18 Proのホーム画面。Build 4のTestFlight実機で画像配信版を確認後に更新する。

画面には第三者の画像・個人情報を含めず、気圧グラフとウィジェットプレビューだけを表示しています。提出前に、App Store Connectが要求する端末サイズ、時刻・データ表示、実際の公開対象端末を最終確認してください。
