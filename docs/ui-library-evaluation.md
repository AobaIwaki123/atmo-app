# UI コンポーネントライブラリ評価レポートと技術選定

本ドキュメントは、気圧監視・気象病対策アプリ `atmo-app` におけるUIコンポーネントライブラリの検証結果、手触りの評価、公的・公式デザインシステムの比較、および最終的なアーキテクチャ選定理由を記録した技術知見です。

---

## 1. 検証の背景と要件

* **目的**: 急激な気圧変化（大気圧の崖）を検知し、頭痛や自律神経過緊張を未然に防ぐための個人用ダッシュボード。
* **要件**:
  - ダークモード基調（暗所や頭痛時でも目に優しい配色）。
  - 直近48時間の気圧推移のスムーズな可視化。
  - 現在の気圧値、急変トレンド（3h変動）、警戒レベルの直感的な把握。
  - **方針**: 「素朴な機能でどこまでいけるか評価し、差がなければ依存が最も軽いもの（外部依存最小）を採用する」。

---

## 2. 検証したライブラリと評価サマリー

独立したPoCブランチを作成し、同一のAPIエンドポイント（`https://atmo.aooba.net/api/v1/pressure`）を接続して手元で動作比較を実施しました。

| ライブラリ / ガイドライン | 参照元 | 検証スコープ | 評価結果・手触り | 採否判定 |
|---|---|---|---|---|
| **fl_chart** | imaNNeo/fl_chart (7.5k+ stars) | 48時間気圧推移の動的ベジェ曲線グラフ、ツールチップ | 滑らかな曲線、現在時刻のドット強調、タップ時ツールチップが極めて優秀。静的PNG画像と比較してアプリの完成度が劇的に向上。 | **採用** |
| **shadcn_ui** | nank1ro/flutter-shadcn-ui | Tailwindライクなモノトーンカード、バッジ、Lucideアイコン | 繊細な境界線とタイポグラフィは好印象。ただし標準機能で同等の質感が再現できたため依存追加を避けて見送り。 | 参考保留 |
| **GetWidget** | ionicfirebaseapp/getwidget | GFCard, GFBadge, GFListTile による総合UIキット | アバターやバッジの装飾が野暮ったく、ミニマルなダークテーマの世界観に合致しなかった。「フォント以外微妙」と判断し却下。 | **却下** |
| **Skeletonizer** | Milad-Akarie/skeletonizer | 既存UIを包むだけのゼロ工数シマースケルトンローディング | API待機中の骨組みシマー体験は非常に優秀。ただしAPI取得が高速なため、初期フェーズの依存最小化を優先して将来拡張枠へ。 | 将来拡張 |
| **デジタル庁デザインシステム** | デジタル庁 (design.digital.go.jp) | カード乱用の全廃、ヒーロー数値解放、WCAG 2.1 AA高コントラスト | 画面の主従関係が明快になり、「管理画面のウィジェット感」が払拭され高評価。 | 比較検証済 |
| **Apple HIG (Apple Weather)** | Apple Human Interface Guidelines | 88pt極薄タイポグラフィ、半透明マテリアル、2列スクエアモジュール | **最高評価**。画面中央に浮かぶ巨大数値の没入感、iOS純正「天気」と同等の洗練された所有欲・完成度を達成。 | **最終採用** |

## 3. 最終採用アーキテクチャ（Apple HIG スタイル）

外部依存は **`fl_chart` の1つのみ**。Flutter標準の描画機能（Cupertino / Material 3）をフル活用したApple Weather純正風レイアウトです。

```text
[ atmo-app 画面構成 (Apple HIG スタイル) ]
  │
  ├─ 1. ヒーローセクション (画面中央)
  │      ├─ 地名: 東京 (28pt, レギュラー)
  │      ├─ メイン数値: 1011.5 hPa (88pt, 超極薄 FontWeight.w200)
  │      └─ 状態ピルバッジ: 急変警戒 (+3.5 / 3h) または 安定
  │
  ├─ 2. 48時間 気圧推移モジュール (fl_chart)
  │      └─ 半透明コンテナ (white 6% alpha, 角丸 22px) 内での滑らかな動的ベジェ曲線
  │
  └─ 3. 2列スクエア・モジュールグリッド (iOS Weather 風)
         ├─ 左タイル: 3時間変動 (+3.5 hPa / 急変注意)
         └─ 右タイル: 現在気温 (20°C / 現在の観測値)
```

## 4. 得られた技術的知見

1. **「四角いカード」を捨て「画面全体をキャンバスにする」**:
   - カード（小箱）を縦に並べると社内ツールのダッシュボードに見えてしまう。数値をカードの外に解放し、画面の主役（ヒーロー）にするだけでプロダクトの品格が跳ね上がる。
2. **Apple HIG とタイポグラフィの力**:
   - 巨大なフォント（88pt）を細身（w200）で配置することで、威圧感を与えずに大気圧の存在感を美しく伝えることができる。
3. **外部依存最小化の圧倒的堅牢性**:
   - 画面の骨格をFlutter標準機能だけで組んだことで、パッケージのEOLやバージョン競合の不安が一切ない最高性能のコードベースが完成した。
