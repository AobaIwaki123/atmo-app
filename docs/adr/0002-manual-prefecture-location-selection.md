# ADR-002: 端末位置情報を使わない代表地点選択

- Status: Accepted
- Date: 2026-11-02
- Supersedes: ADR-001

## Context

atmoは気圧データを地点ごとに表示する必要があります。一方、端末のGPSや位置情報権限を使うと、利用者が意図しない位置情報の取り扱いとApp Store申告が発生します。リリース前に、端末位置情報を使わない方針へ変更します。

## Decision

- 端末の位置情報サービス、GPS、位置情報権限、バックグラウンド追跡を使用しない。
- アプリ内に47都道府県の代表地点を固定カタログとして保持する。
- 都道府県プルダウンと、都道府県名・代表地点名の簡易検索を提供する。
- 選択した都道府県だけをモバイルでは端末内のApp Group領域、Webではブラウザのローカルストレージへ保存し、次回起動時に復元する。
- 気圧APIへは、カタログに定義した代表地点の公開緯度・経度を照会パラメータとして送信する。端末の現在地や住所は送信しない。
- 外部ジオコーディングサービスをアプリから直接呼び出さない。

## Consequences

### Positive

- 位置情報権限の説明・拒否・バックグラウンド追跡を実装・申告する必要がない。
- 利用者は意図した都道府県を明示的に選択できる。
- 代表地点カタログと検索がローカルで完結し、外部ジオコーダーへの依存を増やさない。

### Trade-offs

- 自動で現在地へ追従しないため、利用者が地点を変更する必要がある。
- 代表地点は都道府県内の気圧を近似するもので、市区町村単位の精密な観測地点ではない。
- API側が受け取る座標はユーザー選択による公開代表地点であり、App Store Connectのデータ申告は公開版の実送信内容を確認して最終確定する。
