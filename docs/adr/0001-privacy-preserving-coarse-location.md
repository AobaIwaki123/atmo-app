# ADR-001: ゼロ・インプットと高精度位置情報アクセス根絶を両立するプライバシー保護アーキテクチャ

- **日付**: 2026年10月28日
- **ステータス**: 承認 (Accepted)
- **対象プロダクト**: `atmo-app` (iOS / Web / Android)

---

## 1. 本質的課題と前提条件 (Context)

### 本質的なペイン (Core Vulnerability)
- 従来の気圧アプリ実装では、端末の GPS センサーから高精度な位置情報（約10m精度の緯度経度）を取得し、サーバーへ送信していた。
- これにより、**「アプリ開発者が悪意を持った場合、ユーザーの自宅や職場などのピンポイントな居場所・行動履歴にアクセス・窃取できてしまう」** という構造的なプライバシーリスクが存在していた。

### 考慮すべき制約 (User Experience Constraint)
- 居場所の特定を防ぐ最も単純な解決策は「位置情報（GPS）権限を完全に廃止し、ユーザーに市区町村を手動検索・選択させる方式」である。
- しかし、これは **「移動のたびにユーザーが手動で位置情報を切り替え・選択しなければならない」という重大な新たなペイン（UX の著しい劣化）** を生み出す。

### 設計ゴール
**「ユーザーに手動選択を一切強いることなく（ゼロ・インプットで自動追従）、かつ開発者が悪意を持っても高精度な現在地にアクセスすることが物理的に不可能なアーキテクチャ」** を実現する。

---

## 2. 技術的決定 (Decision)

気圧の変化は大気現象であり、数十km〜数百km規模で緩やかに推移するため、**10m単位の高精度な座標は気圧監視において技術的に一切不要**である。この物理特性を利用し、以下の多層防御を採用する。

### A. iOS ネイティブ: OS レベルの高精度 GPS 物理遮断
- `ios/Runner/Info.plist` に `NSLocationDefaultAccuracyReduced = true` を設定する。
- **効果**:
  - iOS（Core Location）は地球を数キロ四方の固定タイル（メッシュ）に分割し、アプリへ **「タイルの中心座標」** しか供給しない。
  - アプリ内のメモリに生の高精度 GPS が最初から一切届かないため、開発者がコードをどう改ざん・細工しようとも、特定の建物や自宅を特定することは **OS のセキュリティサンドボックスにより物理的に不可能** となる。
  - 許可ダイアログ上でも、ピンポイントな青い点ではなく数キロ圏内の広域円が表示され、ユーザーの心理的不安も払拭される。

### B. Flutter / Web: 低精度モード ＋ 10km クライアント・グリッドスナップ
- 位置情報取得設定（`LocationSettings`）において、高精度 GPS ではなく `LocationAccuracy.reduced`（Web / Android では `LocationAccuracy.low`、`enableHighAccuracy: false`）を要求する。
- 加えて、クライアント側（Dart コード）で受け取った座標を即座に **`0.1度`（約10km四方）の固定メッシュにスナップ（四捨五入）** する関数を導入する。
  ```dart
  // 小数点第1位に丸め（約10km四方のメッシュ代表点へ強制変換）
  double snapToCoarseGrid(double value) => (value * 10).round() / 10;
  ```
- これにより、Web ブラウザ等で仮に生座標が渡ってきた場合であっても、ネットワーク通信（API リクエスト）に流れる座標は 10km 単位の広域代表点のみに限定される。

### C. ゼロ・インプットの維持（フォールバック体験）
- アプリ起動時およびバックグラウンド更新時、OS から渡される「おおよその位置情報」を基に自動で気圧と市区町村名を更新する（ユーザーの手動操作はゼロ）。
- 万が一位置情報の利用が拒否された場合のみ、デフォルト地点（東京等）へフォールバックする。

---

## 3. 結果と評価 (Consequences)

### メリット
1. **高精度位置情報アクセスの完全根絶**:
   - 開発者のサーバーログ、通信パケット、メモリダンプのいずれを検証・傍受しても、手に入るのは「東京都渋谷区周辺の広域メッシュ代表点」のみであり、個人の特定は成立しない。
2. **手動入力ペインの解消**:
   - ユーザーは市区町村を検索・登録・選択するストレスから完全に解放され、アプリを開くだけ、あるいはウィジェットを一瞥するだけで移動先に応じた気圧を把握できる。
3. **App Store 審査の最適化**:
   - App Store Connect の App Privacy において、「データ収集: なし」「追跡なし」を法的に正当性を持って申告可能。

### トレードオフ
- 自治体の境界付近（区境や市境）に位置する場合、数キロの丸めによって隣接する自治体名が表示されるケースがある。
- ただし、気圧の推移グラフおよび急変アラート判定は同一広域エリア内で完全に共通しているため、気象病対策ツールとしての実用性には一切影響を与えない。
